# Remmi

Минималистичный интерактивный прототип Telegram Mini App для задач.

## Возможности

- «Планы»: задачи, сгруппированные по дате, включая задачи без даты.
- «Сегодня»: вертикальный календарь с занятыми интервалами; пересекающиеся события размещаются рядом.
- Создание, изменение, завершение и удаление задач.
- Начало и окончание; длительность по умолчанию — 30 минут.
- Задачи без времени — отдельным списком. Повторов нет.
- Адаптив для 360, 430 и 600 CSS px. Максимальная ширина приложения — 600 px.
- SF Pro Display при наличии на устройстве, иначе системный шрифт. Файлы сторонних шрифтов не включены.

## Запуск

Нужен Node.js 18+. Установка зависимостей не требуется.

```sh
npm run dev
```

Открыть http://127.0.0.1:4317. Для доступа с телефона в той же сети задать HOST равным локальному IP компьютера; PORT необязателен.

```powershell
$env:HOST = "192.168.1.100" # заменить своим IP
npm run dev
```

## Статус

Данные демонстрационные, хранятся в памяти страницы и сбрасываются при перезагрузке. Telegram, авторизация, серверная база и уведомления ещё не подключены. Время интерпретируется в часовом поясе браузера.

План интеграции: серверная проверка Telegram initData, общая база для чата и Mini App, напоминания в назначенное время и ежедневная сводка в 10:00 по часовому поясу пользователя. Добавление через чат в формате «Название / дата и время».
