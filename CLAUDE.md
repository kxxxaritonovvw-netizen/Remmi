# Remmi

Прототип Telegram Mini App для задач и напоминаний. Чистые HTML/CSS/JS без сборки: `dist/index.html`, `dist/style.css`, `dist/app.js`, компоненты в `dist/components/`. Задачи и настройки сохраняются в `localStorage` браузера (ключ `remmi:v1`, только на этом устройстве), стартовый список задач пустой.

## Компоненты
- Компонент — пара файлов `dist/components/<имя>.js` + `.css`, подключается в `index.html` до `app.js`. Сборка демо сама подхватывает всё, что подключено в `index.html`.
- Правки компонента делаем внутри его файлов, не в `style.css`/`app.js`. Приложение только передаёт данные.
- У каждого компонента есть `<имя>.stories.js`: описание, свойства, `spec` (доп. строки спецификации), варианты и `mount` для витрины. В витрине перед вариантами — «Главный компонент» (◆, пунктир): экземпляр по умолчанию с разметкой отступов и высоты и спецификацией, замеренной с живого DOM. Новый компонент подключается в `dist/showcase.html` (css + js + stories).
- Витрина: `dist/showcase.html` (в dev — http://127.0.0.1:4317/showcase.html), `npm run showcase` → `demo-build/showcase.html`, артефакт https://claude.ai/artifact/Na2fyojvc83xJcyBRtTFXg. Витрина грузит только файлы компонентов, без `style.css` приложения — так видно, что компонент изолирован. После правок компонента пересобирать и публиковать и демо, и витрину.
- `Header` (`header.js`/`header.css`) — шапка всех табов: 50px, отступы 20px от краёв экрана, заголовок 20px semibold чёрный (#000), над заголовком необязательный второй уровень `caption` (12px, #8A8490), справа круглая аватарка 32px, включена по умолчанию (`avatar` — фото, `avatarName` — инициалы, иначе силуэт; `showAvatar:false` скрывает). API: `Header(el).render({caption, title, avatar, avatarName, showAvatar})`. Заголовки: «Remmi» / «Сегодня» / «Настройки».
- `TaskItem` (`task-item.js`/`task-item.css`) — строка задачи: круглый чекбокс, название 16px, необязательная мета 12px (дата/время/«Просрочено»), выполненная — закрашенный чекбокс и зачёркнутое название. Скругление 22px, ховер #F4F1F6, мин. высота 76px, строки в карточке разделены линией с отступами 14px. API: `TaskItem({title, meta, done, onToggle, onOpen})` → элемент. Текст меты считает приложение (`row()` в `app.js`); поле ввода и «Добавить задачу» — строки приложения, не компонента.

- В чатах «Components» по умолчанию открывать витрину (сторибук, `showcase.html` / её артефакт), а не рабочее приложение или демо. Демо открывать, только если попросили.
- Правки компонента делаем в общей папке `/Users/alex/Desktop/Remmi` (не в отдельных копиях worktree), чтобы они сразу были у всех чатов этой папки; после правки сообщаем о ней остальным чатам папки.

## Что есть в интерфейсе
- Навбар снизу — таб-бар «Планы / Календарь / Настройки» (иконка над подписью) поверх фэйда с прогрессивным блюром (до 80% цвета фона `#F4F1F6`).
- «Планы»: в шапке «Remmi». Лента секций как в Apple Reminders: Просрочено (только если есть) → Сегодня → Завтра → дни недели (без дат) → «Остаток <месяца>» → месяцы до конца года → следующий год (и более поздние, если есть задачи) → Без даты. «Сегодня» крупнее остальных в 1,5 раза (21px, semibold). Заголовок секции — строка 32px на всю ширину экрана, при наведении/тапе подкрашивается (#E9E5EC); между секциями линия с отступами 20px от краёв экрана (как у контента). Секции с задачами — белые карточки; пустые — только заголовок. Строк «Добавить задачу» нет: тап по заголовку открывает под ним белую карточку ввода без модалки — она «выпадает» из-под заголовка (высота от нуля, содержимое съезжает сверху, 0,42 с, кривая шторки) и при закрытии без текста (Esc, тап мимо) складывается обратно под заголовок за 0,32 с; с текстом задача сразу встаёт на место карточки, при переходе к другой секции старая закрывается мгновенно. `foldComposer()` в app.js) (название; у дней — время, у месяцев/годов/«Без даты» — дата и время). Enter — сохранить и ввести следующую, Esc — закрыть, тап мимо — сохранить набранное и закрыть. У «Просрочено» ввода нет. В секции дня у задачи только время; строки на всю ширину карточки с отступом 2px и ховером.
- «Календарь» (заголовок экрана «Сегодня»): блок «Без времени» + таймлайн. События переносятся, растягиваются за верхний/нижний край (шаг 5 мин, минимум 15), по пустому слоту создаётся событие на 30 мин (мышью — протяжкой).
- «Настройки»: переключатели «Напоминания», «Сводка на день» (в памяти) и справочные строки.
- Эффект при скролле: блоки внизу меньше и ниже, по мере скролла встают на место.
- Мобильная шторка выезжает снизу за 0,5 с (закрытие 0,38 с), страница за ней отъезжает (scale .93, скругление). Анимируются только transform/opacity, блюр навбара на время анимации выключен. Учитывается `prefers-reduced-motion`.

## Отменённые решения (не предлагать снова)
- Серая внешняя карточка с белым списком внутри и «Добавить задачу» на сером — «слишком тяжёлые блоки».

- Сегмент-контрол сверху — заменён таб-баром снизу.
