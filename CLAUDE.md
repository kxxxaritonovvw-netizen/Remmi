# Remmi

Прототип Telegram Mini App для задач и напоминаний. Чистые HTML/CSS/JS без сборки: `dist/index.html`, `dist/style.css`, `dist/app.js`. Данные только в памяти страницы, стартовый список задач пустой.

## Общение
- Отвечать на русском, кратко и по делу.
- Если не уверен, какие фичи делать, сначала дать список на подтверждение, потом делать.

## Git
- Работаем локально на компьютере, облачные сессии не используем.
- Правки коммитить и пушить в рабочую ветку. В `main` пушить только по явной команде.
- Историю не переписывать; если `main` ушёл вперёд — сливать его в ветку, а не ребейзить.

## Несколько компьютеров
- Перед тем как пересесть за другой компьютер: всё закоммитить и запушить, чтобы на GitHub ничего не потерялось.
- На другом компьютере по просьбе «склонируй/обнови репозиторий»: если папки нет — `git clone https://github.com/kxxxaritonovvw-netizen/Remmi.git`, если есть — `git fetch` и `git pull`. Затем сказать, на какой ветке и каком коммите стоим и есть ли ветки новее `main`.
- Если незапушенная работа осталась в рабочей ветке, а не в `main`, — переключиться на неё, а не начинать с `main`.

## Запуск и проверка
- `npm run dev` → http://127.0.0.1:4317
- `npm run check` — синтаксис `dist/app.js`.
- `npm run demo` → `demo-build/index.html`: приложение в рамке 402 × 760 одной страницей, без iframe (так к элементам цепляются комментарии в артефакте). Мобильные стили (≤600px) в демо включены принудительно, шторка открывается внутри рамки.

## Что есть в интерфейсе
- Навбар снизу — таб-бар «Планы / Календарь / Настройки» (иконка над подписью) поверх фэйда с прогрессивным блюром (до 80% цвета фона `#F4F1F6`).
- «Планы»: сверху надпись Remmi над заголовком «Планы» (без даты и счётчика — они только в «Календаре»); задачи по датам в белых карточках; внизу каждой карточки строка «Добавить задачу» с серым кругом-плюсом, подставляет дату блока. Строки на всю ширину карточки с отступом 2px и ховером.
- «Календарь» (заголовок экрана «Сегодня»): блок «Без времени» + таймлайн. События переносятся, растягиваются за верхний/нижний край (шаг 5 мин, минимум 15), по пустому слоту создаётся событие на 30 мин (мышью — протяжкой).
- «Настройки»: переключатели «Напоминания», «Сводка на день» (в памяти) и справочные строки.
- Эффект при скролле: блоки внизу меньше и ниже, по мере скролла встают на место.
- Мобильная шторка выезжает снизу за 0,5 с (закрытие 0,38 с), страница за ней отъезжает (scale .93, скругление). Анимируются только transform/opacity, блюр навбара на время анимации выключен. Учитывается `prefers-reduced-motion`.

## Отменённые решения (не предлагать снова)
- Серая внешняя карточка с белым списком внутри и «Добавить задачу» на сером — «слишком тяжёлые блоки».
- Плавающая кнопка «Новая задача» — заменена строками в карточках.
- Сегмент-контрол сверху — заменён таб-баром снизу.
- Мокап iPhone 16 Pro в демо — выключен, рамка просто 402 × 760.

## Продуктовые приоритеты (мнение, не решение)
Ядро — быстрый ввод из Telegram и надёжные напоминания. Следующим шагом: ввод естественным языком в чате и «Отложить» в напоминании; затем повторы, пересылка сообщений боту, утренняя сводка с просроченным.
