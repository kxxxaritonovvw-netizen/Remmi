# Remmi

Прототип Telegram Mini App для задач и напоминаний. Чистые HTML/CSS/JS без сборки: `dist/index.html`, `dist/style.css`, `dist/app.js`. Данные только в памяти страницы, стартовый список задач пустой.

## Запуск и проверка
- `npm run dev` → http://127.0.0.1:4317
- `npm run check` — синтаксис `dist/app.js`.
- `npm run demo` → `demo-build/index.html`: приложение в рамке 402 × 844 одной страницей, без iframe (так к элементам цепляются комментарии в артефакте). Мобильные стили (≤600px) в демо включены принудительно, шторка открывается внутри рамки.

## Что есть в интерфейсе
- Навбар снизу — таб-бар «Планы / Календарь / Настройки» (иконка над подписью) поверх фэйда с прогрессивным блюром (до 80% цвета фона `#F4F1F6`).
- «Планы»: задачи по датам в белых карточках; внизу каждой карточки строка «Добавить задачу» с серым кругом-плюсом, подставляет дату блока. Строки на всю ширину карточки с отступом 2px и ховером.
- «Календарь» (заголовок экрана «Сегодня»): блок «Без времени» + таймлайн. События переносятся, растягиваются за верхний/нижний край (шаг 5 мин, минимум 15), по пустому слоту создаётся событие на 30 мин (мышью — протяжкой).
- «Настройки»: переключатели «Напоминания», «Сводка на день» (в памяти) и справочные строки.
- Эффект при скролле: блоки внизу меньше и ниже, по мере скролла встают на место.
- Мобильная шторка выезжает снизу с 82% ширины за 0,65 с, страница за ней отъезжает (scale .93, скругление). Учитывается `prefers-reduced-motion`.

## Отменённые решения (не предлагать снова)
- Серая внешняя карточка с белым списком внутри и «Добавить задачу» на сером — «слишком тяжёлые блоки».
- Плавающая кнопка «Новая задача» — заменена строками в карточках.
- Сегмент-контрол сверху — заменён таб-баром снизу.
- Мокап iPhone 16 Pro в демо — выключен, рамка просто 402 × 844.

## Продуктовые приоритеты (мнение, не решение)
Ядро — быстрый ввод из Telegram и надёжные напоминания. Следующим шагом: ввод естественным языком в чате и «Отложить» в напоминании; затем повторы, пересылка сообщений боту, утренняя сводка с просроченным.
